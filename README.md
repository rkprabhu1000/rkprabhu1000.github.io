# rk-portfolio

Personal website for RK Prabhu, built with React, Vite, Tailwind CSS, Motion and Lucide icons.

- **Edit content:** `src/data.ts` (all text, roles, stats, awards, education)
- **Photo:** `public/profile.png`
- **Run locally:** `npm install` then `npm run dev`
- **Build:** `npm run build` (outputs to `dist/`)

## Deploy (GitHub Pages, free)

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes it.
One-time setup in the GitHub repo: **Settings → Pages → Source: GitHub Actions**.

Name the repo `<your-github-username>.github.io` to get the address `https://<your-github-username>.github.io/`.
